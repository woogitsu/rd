    Kartki o dobrowolnej składce

    Jedna kartka na rodzinę, bez danych innych rodzin. Plik jest odczytywany wyłącznie w tej przeglądarce i nigdzie nie jest wysyłany.

    Składka Rady Rodziców jest dobrowolna. Informacja „brak wpisu wpłaty” pochodzi z pliku i może być nieaktualna — wpłata mogła wpłynąć później lub nie zostać jeszcze przypisana. Wybierz rodziny świadomie; lista nie jest wykazem zaległości.

    1. Treść kartki

    Kwota sugerowana (decyzja D-14), dane rachunku (D-13) i szablon (D-16) czekają na decyzję zarządu. Puste pole kwoty lub rachunku pomija odpowiednie zdanie. Gwiazdka (*) oznacza pole wymagane.

    2. Lista rodzin

    Plik CSV (UTF-8, Windows-1250 z Excela PL lub UTF-16 z BOM; separator średnik, przecinek lub tabulator) lub JSON (UTF-8) z kolumnami: ID rodziny, Imię ucznia, Nazwisko ucznia, Klasa oraz opcjonalnie Wpłaty netto EUR. Maksymalnie 2 MB i 5000 wierszy.

      3. Wybór rodzin

      Wybrano 0 rodzin.

      Rodziny do wydruku
      Wybór Rodzina Uczniowie Wpis wpłaty w pliku

      4. Podgląd i druk

      Wydruk: „Drukuj”, a w oknie przeglądarki wybierz drukarkę albo „Zapisz jako PDF”, format A4, skala 100%, bez nagłówków i stopek przeglądarki.
